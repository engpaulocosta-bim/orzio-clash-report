# Contributing

This is a public preview. Start with a small issue or pull request describing a concrete
problem, its expected behavior and an anonymized reproduction. Keep changes focused and
run the Release build/tests documented in README.md. Read AGENTS.md before code changes.

Do not submit client XML, models, generated client reports, screenshots, local paths,
credentials or private project/company names. Use the synthetic/anonymized fixtures in
samples/ or create a minimal synthetic case. Review the whole staged diff before committing.
Deleting sensitive material in a later commit does not remove it from Git history.

Contributions are submitted under the project's MIT license. Submit only material you
have the right to contribute. Preserve third-party license/copyright notices; when a
dependency or bundled runtime changes, update THIRD-PARTY-NOTICES.md and licenses/.

Group counts are not resolved-conflict counts. Keep deterministic output and the distinction
between automated suggestions, explicit human decisions and real-model validation.
