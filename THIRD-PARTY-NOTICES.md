# Third-party licenses and notices

OrzioClashReport code/documentation use the root MIT LICENSE. Dependencies retain
their own copyrights and terms. The following inventory was checked against the
resolved NuGet packages for this source, including transitive/native components.
Full upstream license and bundled component notices are preserved in licenses/;
identical texts are stored once. inventory.json records provenance and SHA-256.

Self-contained Windows distributions include .NET runtime notices. The Inter font's
OFL terms are included separately from the Avalonia wrapper's MIT license. The inventory
also conservatively includes platform/build-only packages; inclusion does not imply
that every platform binary is shipped. Test tools and Inno Setup itself are not bundled.

This inventory covers newly built packages. Existing immutable release files predate
this notice bundle and are not retroactively changed. On every dependency/runtime update,
re-resolve packages, review upstream terms and refresh the full texts and inventory.
